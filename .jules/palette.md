## 2024-05-18 - Progressive Disclosure via Component Info
**Learning:** Global instruction blocks at the top of an application create cognitive overload and take up valuable screen real estate. Users often skip reading them.
**Action:** Use contextual UI hints natively supported by components (like Gradio's `info` attribute) to provide help text exactly where and when the user is interacting with the specific input, keeping the main interface clean and focused.
