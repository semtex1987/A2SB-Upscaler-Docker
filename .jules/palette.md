## 2026-06-26 - Contextual Help in Gradio
**Learning:** Global instruction blocks create cognitive overload. Localized contextual help using `info` attributes or `elem_classes=["text-sm", "text-gray-500", "mb-1"]`, as discovered in Gradio component patterns, drastically improves interface clarity and focus.
**Action:** Prefer contextual helper text over global markdown instructions for future Gradio applications.
