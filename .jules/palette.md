
## 2024-05-18 - Component-Level Helper Text
**Learning:** Moving large, global instructional blocks (like `gr.Markdown`) from the top of the interface down to the specific components they relate to (using the `info` attribute or targeted classes) significantly improves user focus and interface clarity. Users can read instructions precisely when they interact with the relevant component.
**Action:** Prefer localized context (e.g., `info` attribute on inputs) over global instruction blocks to keep the UI clean and contextual.
